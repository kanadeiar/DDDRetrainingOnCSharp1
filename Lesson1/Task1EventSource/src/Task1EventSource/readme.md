Написать программу «Анкета». Последовательно задаются вопросы (имя, фамилия, возраст, рост, вес). В результате вся информация выводится в одну строчку:

в) используя вывод со знаком $.

# QuestionnaireSub.

Основной поддомен анкетирования.

## Назначение

Создание анкеты на основе введенных из консоли данных и вывод данных анкеты разными способами в консоль.

## Глоссарий

Анкета - Questionnaire - контейнер с информацией о имени, фамилии, возрасте, росте и весе.

Создать анкету - QuestionnaireCreate - создать новую анкету с указанными данными.

Анкета создана - QuestionnaireCreated - событие о том, что была создана новая анкета.

Текст - Text - форматированные определенным форматом сведения из анкеты.

Формат - Format - способ форматирования текста анкеты.

Форматированние текста - FormatText - создание определенным выбранным способом текста на основе сведений из анкеты.

Консоль - Console - консольный интерфейс взаимодействия с пользователем.

## Сценарии

- Ввод данных из консоли в анкету.

- Печать данных из анкеты в консоль.

## Инструменты

1) Предметное проектирование.

2) Модель предметной области, основанная на событиях.

3) CQRS.

4) Пирамида тестирования.
