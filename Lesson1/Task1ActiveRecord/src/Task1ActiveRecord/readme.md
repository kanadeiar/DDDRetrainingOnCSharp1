# QuestionnaireSub.

Вспомогательный субдомен анкетирования.

## Назначение

Создание анкеты на основе введенных из консоли данных и вывод данных анкеты разными способами в консоль.

## Глоссарий

Анкета - Questionnaire - контейнер с информацией о имени, фамилии, возрасте, росте и весе.

Создать - Create - создать новую анкету с указанными данными.

Текст - Text - форматированные определенным форматом сведения из анкеты.

Формат - Format - способ форматирования текста анкеты.

Форматированние текста - FormatText - создание определенным выбранным способом форматирования текста на основе сведений из анкеты.

Консоль - Console - консольный интерфейс взаимодействия с пользователем.

## Сценарии

- Ввод данных из консоли в анкету.

- Печать даных из анкеты в консоль.

## Инструменты

1) Предметное проектирование.

2) Активная запись.

3) Слоеная архитектура (4 слоя).

4) Ромб тестирования.
